# 开源地图项目参考（选型与迁移建议）

> 调研日期：2026-11-17。Star 数为当日 GitHub 页面快照，仅作热度参考；引入前请再次核对 License 与维护状态。

## 1. 结论（先看这里）

按「拿来即用 → 中期升级 → 只作参考 → 谨慎使用」排序：

### P0 可直接引入（底图仍用天地图，改动可控）

| 项目 | 用途 | 落到本项目 | 状态 |
|---|---|---|---|

### 谨慎 / 不建议

| 项目/做法 | 原因 |
|---|---|
| `mapbox/mapbox-gl-js` v2+ | 非 OSI 开源，商用需授权；需要 GL 能力请用 MapLibre |
| `GeoNode` / `MapStore` | 完整 GIS 平台，技术栈重（Django/Java），与本项目不匹配 |
| 天地图瓦片下载器（geo-downloader、tianditu-python） | 可能违反天地图服务条款，仅可用于自有授权数据的离线场景 |
| AGPL 项目（uMap、mapdraw） | 参考设计可以；直接拷代码到网络服务有传染性 |
| 用第三方 GeoJSON 直接替换现有省/市/县边界 | 坐标系与精度来源不明，容易引入整体偏移 |

## 3. 针对本项目的落地路径

### 阶段 1：低风险增强（已完成）

1. **后台地图组件组件化**
   - 文件：`apps/admin-web/src/components/MapPicker.vue`、`MapPathEditor.vue`
   - 做法：Leaflet 1.9 + Geoman 2.20，天地图 WMTS 直连；保留原有 props/emits 与数据结构
   - 收益：去掉手写脚本加载、事件绑定和弹窗生命周期处理；支持顶点编辑

2. **H5 点位聚合**
   - 文件：`apps/map-web/index.html` 的 `renderMarkers()`
   - 做法：`vendor/supercluster.min.js` 按视口与 zoom 聚合；聚合点点击后按扩展级别下钻
   - 收益：标签数量上千后不重叠、不掉帧

3. **服务端精确空间校验**
   - 文件：`apps/api/app/core/geo.py`、`apps/api/app/services/map_service.py`
   - 做法：Shapely `covers(Point, Polygon)`；边界文件缺失时回退外接矩形
   - 收益：省外但落在外接矩形内的坐标会被正确拒绝

4. **贵州区划数据校订**
   - 文件：`apps/map-web/data/guizhou-counties.json`
   - 做法：AreaCity 2026-04 数据核对，修正水城区（520204）、黔西市（520581）编码
   - 限制：AreaCity 免费版乡镇只有名称/编码，坐标与边界为付费数据；详见 `docs/数据校验-贵州行政区划.md`

### 阶段 2：2.5D 技术验证（独立分支）

- 新建 `apps/map-web/25d.html`（不改现有主流程），用 MapLibre GL JS：
  - 底图：天地图 `img_w` WMTS 通过 raster source 接入；
  - 2.5D：`map.setPitch()/setBearing()` + 区域/路线 `fill-extrusion` / 抬高线；
  - 可选：接公开 DEM 做真实地形起伏（需评估数据源与配额）；
  - 点位：symbol 图层 + 分类图标。
- 小程序 2.5D 实验页继续保留；若后续要更真实的地形，再参考 `three-geo` 或 Cesium。

### 阶段 3：编辑器继续升级（可选）

- 后台已使用 Leaflet + Geoman；若后续需要吸附到既有边界、撤销栈或批量编辑，
  再评估 Geoman 的 snapping / 自定义工具栏；
- H5 如需在线编辑，可复用同一套 Leaflet + Geoman 方案，数据结构保持不变。

### 阶段 4：数据量与发布

- 当前 `map.json` 全量快照在 POI 数千级、边界 JSON 数 MB 级完全够用；
- 仅当数据量显著增长或需要矢量瓦片时，再引入 PMTiles / Martin / Tippecanoe。

## 4. 合规与坐标系检查清单

1. **天地图 Key**
   - 浏览器端 Key 与小程序端 Key 类型不同；
   - 配置域名白名单，不要把服务端 Key 暴露到前端；
   - H5 与后台可共用一个浏览器端 Key，但需确认配额。
2. **天地图服务条款**
   - 不得批量下载、长期缓存、转售瓦片；
   - `geo-downloader`、`tianditu-python` 只能作为工具参考，默认不用于生产。
3. **坐标系**
   - 天地图为 CGCS2000/WGS84；
   - 高德/腾讯来源数据为 GCJ-02，入库前必须转换；
   - 引入第三方边界数据必须抽样比对现有数据。
4. **License**
   - Mapbox GL JS v2+ 非 OSI 开源；
   - uMap、mapdraw 为 AGPL-3.0；
   - GeoNode 为 GPL；
   - Cesium 为 Apache-2.0，iD 为 ISC，Leaflet/OpenLayers 为 BSD-2。
5. **数据版权**
   - 行政区边界可能另有来源许可，文档中记录数据来源与获取日期。
6. **依赖管理**
   - 新增前端/后端依赖锁定版本，并同步 `docs/操作日志.md` 与相关设计文档。

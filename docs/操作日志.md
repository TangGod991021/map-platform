## 2026-11-17 · 开源地图项目调研

### 目标

- 调研 GitHub 上可迁移/可参考的地图项目，评估与「天地图卫星 + 标签管理 + 发布快照」架构的匹配度。

### 产出

- 新增 `docs/开源地图项目参考.md`：按「底图引擎 / 点位编辑 / 2.5D / 小程序 / 边界数据 / 空间计算 / 瓦片发布」分类整理；
- 结论优先级：
  - P0：`vue-tianditu`（后台地图组件）、`supercluster`（H5 聚合）、`turf`/`shapely`（空间计算）、`AreaCity`（乡镇边界）；
  - P1：`MapLibre GL JS`（2.5D）、`Leaflet + ChineseTmsProviders + Geoman`（换引擎方案）、`OpenLayers`（专业 GIS）；
  - P2：uMap / Placemark / iD（编辑交互参考）、NFU-Guide-Map 等小程序（功能形态参考）。
- 更新 `docs/README.md` 文档索引。

### 风险提示

- Mapbox GL JS v2+ 非 OSI 开源，GL 能力改用 MapLibre；
- uMap / mapdraw 为 AGPL-3.0，只参考设计不拷代码；
- 天地图瓦片下载器存在服务条款风险，默认不用于生产；
- 引入第三方边界数据前需核对坐标系（WGS84 vs GCJ-02）。

### 验证

- 本项目未改动业务代码与依赖，仅新增/更新文档。

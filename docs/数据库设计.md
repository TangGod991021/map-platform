# 数据库设计

> 开发默认 SQLite（`apps/api/data/map_platform.db`）；生产建议 MySQL 8.0。
> 坐标统一存 WGS84/CGCS2000；高德/腾讯来源需先 GCJ-02 → WGS84。

## 1. 表清单

| 表 | 说明 |
|---|---|
| `sys_user` | 管理员账号 |
| `map_category` | 地图分类 |
| `map_label` | 标签/点位 |
| `map_route` | 路线 |
| `map_area` | 区域 |
| `map_release` | 发布版本 |

## 7. MySQL DDL（节选）

```sql
CREATE TABLE sys_user (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  username VARCHAR(64) NOT NULL UNIQUE,
  password_hash VARCHAR(255) NOT NULL,
  nickname VARCHAR(64) DEFAULT '',
  role VARCHAR(32) DEFAULT 'admin',
  permissions TEXT,
  status CHAR(1) DEFAULT '0',
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP
) COMMENT='系统用户';

CREATE TABLE map_category (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  code VARCHAR(32) NOT NULL UNIQUE,
  name VARCHAR(32) NOT NULL,
  color VARCHAR(16) DEFAULT '#00e5ff',
  icon VARCHAR(255) DEFAULT '',
  sort INT DEFAULT 0,
  status CHAR(1) DEFAULT '0',
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
) COMMENT='地图分类';

CREATE TABLE map_label (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  category_id BIGINT NULL,
  name VARCHAR(64) NOT NULL,
  subtitle VARCHAR(128) DEFAULT '',
  lng DOUBLE NOT NULL,
  lat DOUBLE NOT NULL,
  address VARCHAR(255) DEFAULT '',
  summary VARCHAR(500) DEFAULT '',
  description TEXT,
  cover_image VARCHAR(500) DEFAULT '',
  images TEXT,
  tags TEXT,
  phone VARCHAR(64) DEFAULT '',
  business_hours VARCHAR(128) DEFAULT '',
  sort INT DEFAULT 0,
  status CHAR(1) DEFAULT '0',
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  KEY idx_map_label_category (category_id),
  KEY idx_map_label_status (status),
  KEY idx_map_label_name (name)
) COMMENT='地图标签/点位';

CREATE TABLE map_route (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  name VARCHAR(64) NOT NULL,
  color VARCHAR(16) DEFAULT '#00e5ff',
  weight INT DEFAULT 4,
  description VARCHAR(500) DEFAULT '',
  points TEXT,
  sort INT DEFAULT 0,
  status CHAR(1) DEFAULT '0',
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
) COMMENT='地图路线';

CREATE TABLE map_area (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  name VARCHAR(64) NOT NULL,
  color VARCHAR(16) DEFAULT '#8b5cf6',
  description VARCHAR(500) DEFAULT '',
  polygon TEXT,
  sort INT DEFAULT 0,
  status CHAR(1) DEFAULT '0',
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
) COMMENT='地图区域';

CREATE TABLE map_release (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  version INT NOT NULL UNIQUE,
  note VARCHAR(255) DEFAULT '',
  snapshot_path VARCHAR(500) DEFAULT '',
  created_by VARCHAR(64) DEFAULT '',
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP
) COMMENT='地图发布版本';
```

## 8. 迁移

当前骨架使用 `Base.metadata.create_all()` 快速建表。生产建议：

```bash
pip install alembic
alembic init alembic
# 配置 sqlalchemy.url 指向 DATABASE_URL
alembic revision --autogenerate -m "init map tables"
alembic upgrade head
```

后续每次改 ORM 都生成迁移，禁止生产直接 `create_all`。

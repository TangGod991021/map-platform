# 部署指南

> 建议部署目录：`/data/map-platform`
> 后端端口：`11000`（与现有爬虫 10938、管理系统 8080 隔离）
> 管理端域名：`map-admin.mengyu.live`
> 地图 H5：`tianmap.mengyu.live`（继续使用现有静态站点，内容换成新项目 `apps/map-web`）

## 1. 服务器准备

```bash
mkdir -p /data/map-platform
# 将项目上传/克隆到该目录
```

## 2. 后端

```bash
cd /data/map-platform/apps/api
python3.12 -m venv .venv
source .venv/bin/activate
pip install -e .
cp .env.example .env
# 编辑 .env：DATABASE_URL / JWT_SECRET / CORS_ORIGINS / MAP_PUBLISH_DIR
alembic upgrade head
```

> 表结构统一由 Alembic 管理；老库首次接入时先 `alembic stamp head` 标记基线，再做后续迁移。

生产 MySQL：

```bash
pip install -e ".[mysql]"
```

```env
DATABASE_URL=mysql+asyncmy://user:pass@127.0.0.1:3306/map_platform?charset=utf8mb4
JWT_SECRET=请替换为长随机串
MAP_PUBLISH_DIR=/data/map-platform/apps/map-web/data
UPLOAD_DIR=/data/map-platform/apps/api/data/uploads
```

启动：

```bash
.venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 11000
```

systemd：

```bash
cp deploy/systemd/map-platform-api.service /etc/systemd/system/
systemctl daemon-reload
systemctl enable --now map-platform-api
systemctl status map-platform-api
```

## 3. 管理前端

本地：

```bash
cd apps/admin-web
npm install
npm run build
```

产物 `apps/admin-web/dist` 上传到：

```text
/data/map-platform/apps/admin-web/dist
```

## 4. 地图 H5

`apps/map-web` 是纯静态站点，部署到：

```text
/data/map-platform/apps/map-web
```

Nginx 指向该目录；`config.js` 填天地图 Key。后台发布后生成：

```text
apps/map-web/data/map.json
apps/map-web/data/manifest.json
```

`apps/map-web/vendor/` 是点位聚合所需的第三方构建（supercluster 9.1.0），
部署时需与 `index.html` 一起拷贝，不能遗漏。

## 5. Nginx

参考 `deploy/nginx/map-platform.conf`：

- `map-admin.mengyu.live`
  - `/` → admin-web dist
  - `/prod-api/` → `127.0.0.1:11000`
  - `/profile/` → `127.0.0.1:11000`
- `tianmap.mengyu.live`
  - `/` → apps/map-web
  - `/map-api/` → `127.0.0.1:11000`（可选，静态快照优先）

证书：`certbot --nginx -d map-admin.mengyu.live`（tianmap 已有证书则复用）。

## 6. 小程序

导入 `apps/miniprogram`。

- `apps/miniprogram/config.js` 的 `mapBaseUrl` 指向地图 H5；
- 生产：`https://tianmap.mengyu.live/`；
- 本地联调：`http://<局域网IP>:8081/`（需在开发工具关闭域名校验）。

## 7. 发布流程

1. 管理端维护标签，状态设为「已发布」；
2. 进入「发布管理」→ 发布地图快照；
3. 后端写入 `apps/map-web/data/map.json`；
4. H5 刷新即可看到新标签；
5. 小程序 web-view 重新进入即可。

## 8. 回滚

`map_release` 记录每次版本；回滚时：

```bash
# 备份当前 map.json
cp apps/map-web/data/map.json apps/map-web/data/map.json.bak
# 从历史版本恢复（需提前保存历史快照）
```

后续在发布管理页增加「回滚」按钮，自动复制历史快照。

## 9. 备份

- MySQL：`mysqldump` 每日备份；
- 媒体：`apps/api/data/uploads` 定期归档；
- 快照：`apps/map-web/data/map.json` 与 manifest 保留最近 N 个版本。

## 10. 安全

- 修改默认 `admin/admin123`；
- 生产 `JWT_SECRET` 必须随机；
- 上传目录禁止执行；
- 公开 API 限流（Nginx `limit_req`）；
- 富文本发布前白名单过滤。
